# Airlock v0.1.6 - クロスプラットフォーム npm インストーラーリリース

リリース日: 2026 年 8 月 2 日

[English](v0.1.6.md) | [简体中文](v0.1.6.zh-CN.md) | [日本語](v0.1.6.ja.md)

## 追加

- `airlock-installer install` がすべての対応デスクトッププラットフォームで動作:
  - macOS 12+：Apple Silicon（同梱 DMG）と Intel（release DMG）；
  - Windows 10+：x64、x86（i686）、arm64（固定 checksum NSIS installer）；
  - Linux x64 / arm64（固定 checksum AppImage を `~/.local/bin` にインストール）。
- 各プラットフォームは固定 release asset をダウンロードし、公開契約と SHA-256
  を照合。不一致または未公開の場合は fail-closed します。
- CI が macOS x64 DMG と Linux x64/arm64 の AppImage/deb を生成し、固定
  checksum 付きで release に添付します。

## リリース境界

macOS arm64 は引き続き検証済みの ad-hoc 署名リリースです。macOS x64、Windows、
Linux preview installer は未署名で、SmartScreen・Gatekeeper・FUSE 欠如などの
追加手順が必要な場合があります。Linux ARMv7（Raspberry Pi）は Core/CLI のみで
Desktop bundle はありません。

## 検証

```bash
npm install -g airlock-relay && airlock-installer doctor
```

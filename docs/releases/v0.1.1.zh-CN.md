# Airlock v0.1.1 - 技术预览版

发布日期：2026 年 7 月 31 日

[English](v0.1.1.md) | [简体中文](v0.1.1.zh-CN.md) | [日本語](v0.1.1.ja.md)

Airlock v0.1.1 是原生固定路由凭据隔离转发器的技术预览版本。它让 Agent、LLM、脚本或
可信局域网设备使用受限的 HTTP、SSH、LLM 路由，而不获得真实上游地址、密码、私钥或
供应商 API Key。

## 本版更新

- `airlockd` 可脱离桌面端以 Server 模式运行；通过当前用户专属 Unix Socket 的
  `airlock` CLI 运维，并可选择独立认证、只监听 loopback 的 Web UI。
- 支持在同一 SSH 监听地址配置多个映射：不同本地用户名映射独立上游账户，支持指定
  上游 SSH 端口、轮换本地凭据与手动健康检查。
- 新安装继续默认使用标准 `0600` 本地 SecretStore，避免反复出现 macOS 密码提示；
  macOS Keychain 仍保留为可选择的更严格存储方案。
- 提供经校验的 npm 安装器入口、多语言产品与运维文档，以及 GitHub Pages 部署。

## 下载与校验

本版只支持 **Apple Silicon 且 macOS 12 或更高版本**。

- `Airlock_0.1.1_aarch64.dmg`
- `Airlock_0.1.1_aarch64.app.zip`
- `SHA256SUMS-v0.1.1.txt`

```text
644b7310e51ebbd2668a40ee95699194903f3d73347a6c071f2b4140bffefc9b  Airlock_0.1.1_aarch64.dmg
72e7bc174e53c901cbca9a52af92615bb4e44ff094d19d919a112cc66824125a  Airlock_0.1.1_aarch64.app.zip
```

打开应用前执行：

```bash
shasum -a 256 -c SHA256SUMS-v0.1.1.txt
```

随后阅读[安装指南](../installation.zh-CN.md)。

## 安全与范围

本版是**预发布技术预览**，不是生产安全承诺。应用采用 ad-hoc 签名，尚无 Apple
Developer ID 签名和公证。请仅从官方 Release 下载，先核验校验值，再按 Gatekeeper
说明完成首次启动。

本版已通过 Go、Rust、前端、npm 包、产物校验和严格代码签名检查，但尚未完成独立生产
安全审计。局域网入口必须保持私有；开启不受限 SSH exec 时，应使用专用最小权限上游
账户；开启 SSH 命令审计后，命令参数中不得包含 Secret。使用真实凭据前请阅读
[安全策略](../../SECURITY.md#简体中文)。

## 已知限制

- 未提供 Intel macOS、Windows 或 Linux 安装包。
- 未提供 Developer ID 签名与 Apple 公证。
- Capability 暂无 TTL、一次性凭据或逐连接审批。
- LLM 用量为可选内存统计，不是计费记录。

完整内容见[更新日志](../../CHANGELOG.md)、[服务端运维指南](../server-deployment.zh-CN.md)
和 [Airlock 文档网站](https://louisonh.github.io/airlock-relay/)。

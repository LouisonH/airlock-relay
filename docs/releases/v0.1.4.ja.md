## セキュリティ更新

- `golang.org/x/crypto` を `v0.52.0` へ更新し、旧依存関係の SSH 呼び出し経路で到達可能な
  脆弱性を修正しました。
- 同時 SSH 接続数と session 数を制限し、到達可能な listener が無制限にコア資源を使うことを
  防ぎます。
- ゲートウェイ全体で同時 HTTP response stream 数を制限しました。LLM route には、従来どおり
  route ごとの RPM と concurrency 制限もあります。
- 保守者による本番運用準備セキュリティ監査を完了しました。対象範囲、検証、残る運用境界は
  [監査記録](../security-audit-2026-07-31.md) を確認してください。

## リリース境界

本版は macOS Apple Silicon 向け technical preview のままです。監査は保守者が実施したもので、
独立した第三者認証ではありません。アプリは ad-hoc 署名で Apple 公証も未完了です。同一ユーザー
で動く非信頼プロセスへの耐性が必要な場合は Keychain Strict を使い、LAN ingress は private に
保ち、上流 SSH には最小権限アカウントを使用してください。

[security policy](../../SECURITY.md)、[installation guide](../installation.md)、
[changelog](../../CHANGELOG.md) も確認してください。

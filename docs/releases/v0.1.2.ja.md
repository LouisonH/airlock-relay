# Airlock v0.1.2 - 起動ホットフィックス

リリース日: 2026 年 7 月 31 日

[English](v0.1.2.md) | [简体中文](v0.1.2.zh-CN.md) | [日本語](v0.1.2.ja.md)

## 修正内容

- Desktop は sidecar が実際に起動完了したかを確認し、「ローカルコアを待機中」のままにしません。
- コア起動失敗時も UI を維持し、再試行と、ポート競合または制御チャネル問題のサニタイズ済み理由を表示します。
- 制御状態の取得とコア再起動を UI 実行経路から分離し、ローカル Socket の停止でアプリが固まりません。
- npm installer は DMG を開くだけではなく、検証済み `Airlock.app` を `~/Applications` に
  原子的に導入します。`--open` は導入成功後だけ起動します。

## ダウンロードと検証

- `Airlock_0.1.2_aarch64.dmg`
- `Airlock_0.1.2_aarch64.app.zip`
- `SHA256SUMS-v0.1.2.txt`

```text
e67082c731219cf6a9a9a282c10671ab831e66b1061c38bfcbf55b4fb7c065a5  Airlock_0.1.2_aarch64.dmg
c03a40de7f693533f8011472cd10418f76e1c20bc47a4d51dd0b004ca19f51fc  Airlock_0.1.2_aarch64.app.zip
```

```bash
npm install -g airlock-relay && airlock-installer install --open
```

[installation guide](../installation.md) と [security policy](../../SECURITY.md) を確認してください。

この版も macOS Apple Silicon 向け technical preview です。ad-hoc 署名で Apple の公証は
ありません。初回起動前に checksum を確認してください。

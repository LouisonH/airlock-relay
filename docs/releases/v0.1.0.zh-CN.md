# Airlock v0.1.0 - 技术预览版

发布日期：2026 年 7 月 30 日

[English](v0.1.0.md) | [简体中文](v0.1.0.zh-CN.md)

Airlock v0.1.0 是这款原生凭据隔离转发器的第一个可下载技术预览版。它让 Agent、
LLM、脚本或同一局域网的其他设备使用边界明确的路由，而无需获得受保护的上游 URL、
账户密码、SSH 身份或供应商 API Key。

## 主要内容

- 支持 Range 流式下载的固定路由 HTTP/Wget 转发。
- 双会话 SSH 中转，提供独立本地认证、严格上游 Host Key 固定、可自定义的精确命令模式、
  经高风险确认的所有非交互 exec，以及可选命令记录。
- OpenAI-compatible 与 Anthropic-compatible LLM 路由，支持独立二次 API Key、模型与
  输出限制、速率/并发策略、SSE 流式转发和可选内存调用/Token 统计。
- 直连、Clash 兼容代理及自动出口选择。
- 默认采用免启动密码弹窗的 `0600` 本地文件，并可选择更严格的 macOS Keychain，
  支持两者间的引导迁移。
- 原生 Tauri 桌面界面，支持浅色/深色/系统外观、配色、信息密度、动效和刷新偏好。
- 默认仅 loopback，也可在明确确认后为可信本地网络开启私有局域网中转。

## 下载

本版支持 **Apple Silicon** 和 **macOS 12 或更高版本**。

- `Airlock_0.1.0_aarch64.dmg`
- `Airlock_0.1.0_aarch64.app.zip`
- `SHA256SUMS.txt`

安装前请核验：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

随后按照[安装指南](../installation.zh-CN.md)操作。

## 安全提示

这是预发布技术预览版，并不代表已达到生产安全等级。应用已进行 ad-hoc 签名，但没有
Apple Developer ID 签名，也没有经过 Apple 公证；首次启动时 macOS 会显示未知开发者
警告。代码通过了自动化 Race、单元、集成、前端、Rust 与 Lint 检查，但尚未完成独立
生产安全审计。

使用真实凭据前请阅读[安全策略与威胁边界](../../SECURITY.md#简体中文)，尤其注意：

- v0.1.0 的本地 Capability 没有 TTL，也不是一次性凭据。
- 局域网模式不得映射到公网。
- 不受限 SSH exec 实际上等同于配置的上游用户执行远程命令。
- 命令审计会记录完整命令，可能包含敏感参数。
- LLM Token 统计不持久化提示词或响应正文，但 sidecar 重启后计数会清零。

## 已知限制

- 暂无 Intel、Windows 或 Linux 二进制安装包。
- 暂无 Developer ID 签名与 Apple 公证。
- 暂无 TTL、一次性 Capability 与逐连接授权流程。
- 桌面端暂不支持轮换 HTTP/SSH Capability。
- LLM Usage 和限制为内存状态，不是持久计费系统。
- 关闭主窗口后 Airlock 会保留在菜单栏；需要从菜单栏选择**退出**才能停止 sidecar。

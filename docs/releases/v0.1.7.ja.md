# Airlock v0.1.7 - ウィンドウ操作とインストーラー修正

リリース日: 2026 年 8 月 3 日

[English](v0.1.7.md) | [简体中文](v0.1.7.zh-CN.md) | [日本語](v0.1.7.ja.md)

## 修正

- カスタムタイトルバーが全プラットフォームで動作します。最小化、最大化/復元、
  閉じる、ドラッグ領域が、Tauri の capability が読み取り専用のウィンドウ権限
  しか持たなかったために暗黙的に拒否されていました。必要な権限を明示的に
  付与しました。
- Windows インストーラーの後片付け：一時ファイルがロックされていても、
  成功したインストールをエラーにしません（npm インストーラーパッケージ
  0.1.8/0.1.9）。

## 検証

- `Airlock_0.1.7_aarch64.dmg` / `Airlock_0.1.7_x64.dmg`
- Windows `Airlock_0.1.7_x64/x86/arm64-setup.exe`
- Linux `Airlock_0.1.7_amd64/aarch64.AppImage`
- Release ページの `SHA256SUMS-v0.1.7.txt`

インストール:

```bash
npm install -g airlock-relay && airlock-installer install --open
```

詳しくは[インストールガイド](../installation.md)と[更新履歴](../../CHANGELOG.md)。

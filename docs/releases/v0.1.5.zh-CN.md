# Airlock v0.1.5 - 交互式 Shell 与跨平台引导版本

发布日期：2026 年 8 月 1 日

[English](v0.1.5.md) | [简体中文](v0.1.5.zh-CN.md) | [日本語](v0.1.5.ja.md)

## 新增

- 可选的路由级交互式 SSH Shell，默认关闭。设置
  `allow_interactive_shell: true`（要求同时开启 `allow_all_commands: true`）
  后，PuTTY 与 `ssh` 客户端可直接进入上游 Shell，Airlock 仍注入存储的上游
  凭据；只有开启该开关时才会向上游转发 PTY 元数据。
- 非交互路由收到普通 Shell 请求时，返回可操作的引导信息而不是拒绝；配置了
  单条精确命令的路由会直接执行该命令。
- SSH 命令受保护关键字出口改写。
- 显式的路由级 SFTP 权限，默认关闭，供现代 `scp`/SFTP 客户端使用。
- Windows x64/x86/arm64 与 Linux x64/arm64/ARMv7 的 Core 与 CLI 交叉编译，
  包括所有者专用 Windows 命名管道控制、Credential Manager / Secret Service
  凭据后端、Linux 原生提示，以及失败关闭的 CI 预览安装器契约。Windows 预览
  安装包随本版本发布供手动测试，仍为未签名预览产物，而非公开固定校验和
  安装器。

## 修复

- 交互式 Shell 的 PTY 尺寸此前被转置转发，导致终端输入显示混乱；上游会话
  现在收到客户端真实的行数与列数。

## 发布边界

这仍是 macOS Apple Silicon 技术预览版。[v0.1.4](v0.1.4.zh-CN.md) 完成的生产
就绪审计继续适用；它不是独立第三方认证。应用仍为 ad-hoc 签名且未经 Apple
公证。同用户敌意进程防护请使用 Keychain Strict 配置，保持局域网入口私有，
并使用最小权限的上游 SSH 账号。

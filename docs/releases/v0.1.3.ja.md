# Airlock v0.1.3 - ポート復旧リリース

リリース日: 2026 年 7 月 31 日

[English](v0.1.3.md) | [简体中文](v0.1.3.zh-CN.md) | [日本語](v0.1.3.ja.md)

## 主な更新

- Desktop にローカルリスナーポート管理を追加しました。HTTP と SSH は、それぞれ
  `1024-65535` の異なる非特権ポートに変更できます。
- 現在の macOS ユーザーが設定ポートを使用しているプロセスを検出し、実行直前に PID
  を再確認したうえで、二次確認付きの通常終了リクエストを送ります。強制終了は行わず、
  Airlock 自身の sidecar は一覧から除外します。
- ローカルコアがオフラインでも新しいポートを保存できます。起動に失敗した場合は旧設定へ
  自動的に戻ります。
- 旧設定にポートがない場合は、既定の `4768` と `4770` を補います。

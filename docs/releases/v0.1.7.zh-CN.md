# Airlock v0.1.7 - 窗口控制与安装器修复

发布日期：2026 年 8 月 3 日

[English](v0.1.7.md) | [简体中文](v0.1.7.zh-CN.md) | [日本語](v0.1.7.ja.md)

## 修复

- 自定义桌面顶栏现在在所有平台可用。最小化、最大化/还原、关闭与拖动区域此前
  因 Tauri 能力集只授予了只读窗口权限而被静默拒绝；现已显式授予所需权限。
- Windows 安装器清理：临时安装文件被锁定时，不再把成功安装变成报错
  （npm 安装器包 0.1.8/0.1.9）。

## 验证

- `Airlock_0.1.7_aarch64.dmg` / `Airlock_0.1.7_x64.dmg`
- Windows `Airlock_0.1.7_x64/x86/arm64-setup.exe`
- Linux `Airlock_0.1.7_amd64/aarch64.AppImage`
- Release 页的 `SHA256SUMS-v0.1.7.txt`

安装：

```bash
npm install -g airlock-relay && airlock-installer install --open
```

详见[安装指南](../installation.zh-CN.md)与[更新日志](../../CHANGELOG.md)。

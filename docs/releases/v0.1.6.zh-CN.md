# Airlock v0.1.6 - 全平台 npm 安装器发布

发布日期：2026 年 8 月 2 日

[English](v0.1.6.md) | [简体中文](v0.1.6.zh-CN.md) | [日本語](v0.1.6.ja.md)

## 新增

- `airlock-installer install` 现在支持所有桌面平台：
  - macOS 12+：Apple Silicon（内置 DMG）与 Intel（发布 DMG）；
  - Windows 10+：x64、x86（i686）、arm64（固定校验和 NSIS 安装器）；
  - Linux x64 与 arm64（固定校验和 AppImage，安装到 `~/.local/bin`）。
- 各平台下载固定校验和的发布产物，与已发布契约比对 SHA-256，不一致或产物
  未发布时失败关闭。
- CI 新增 macOS x64 DMG 与 Linux x64/arm64 AppImage/deb 安装器产物，全部随
  Release 附上固定校验和。
- Linux AppImage/deb 产物使用 `Airlock Release Signing` 密钥做 GPG 签名；
  公钥与分离签名（`Airlock-gpg-pubkey.asc` 与 `.sig` 文件）随 Release 发布。
- 树莓派支持：64 位 Raspberry Pi OS 直接安装已发布的 arm64 AppImage；
  32 位 armv7 用户可在树莓派上运行 `scripts/build-armv7-desktop.sh`
  构建桌面包。

## 发布边界

macOS arm64 仍是经核验的 ad-hoc 签名版本。macOS x64、Windows 与 Linux 预览
安装器未签名：可能遇到 SmartScreen、Gatekeeper 或缺少 FUSE 的额外步骤。
Linux ARMv7（树莓派）仍仅提供 Core/CLI，没有桌面包。

## 验证

```bash
npm install -g airlock-relay && airlock-installer doctor
```

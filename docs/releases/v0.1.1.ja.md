# Airlock v0.1.1 - テクニカルプレビュー

リリース日: 2026 年 7 月 31 日

[English](v0.1.1.md) | [简体中文](v0.1.1.zh-CN.md) | [日本語](v0.1.1.ja.md)

Airlock v0.1.1 は、ネイティブ固定ルート認証情報分離リレーのテクニカルプレビューです。
Agent、LLM、スクリプト、または信頼できる LAN デバイスは、実際の上流アドレス、password、
秘密鍵、provider API Key を受け取ることなく、制限された HTTP、SSH、LLM ルートを使用できます。

## 主な更新

- Desktop なしで `airlockd` を Server mode で稼働し、ユーザー専用 Unix Socket の
  `airlock` CLI で管理できます。任意の Web UI は個別認証かつ loopback 専用です。
- 共有 SSH listener 上で複数 mapping を構成し、ローカル username ごとに保護された
  upstream account を選択できます。upstream port、ローカル認証情報 rotation、手動 health
  check にも対応します。
- 新規インストールの標準はパスワード要求を繰り返さない `0600` ローカル SecretStore です。
  より厳格な macOS Keychain は opt-in として残ります。
- 検証済み npm installer、複数言語の製品・運用ドキュメント、GitHub Pages 配信を追加しました。

## ダウンロードと検証

このリリースは **Apple Silicon / macOS 12 以降** のみ対応します。

- `Airlock_0.1.1_aarch64.dmg`
- `Airlock_0.1.1_aarch64.app.zip`
- `SHA256SUMS-v0.1.1.txt`

```text
644b7310e51ebbd2668a40ee95699194903f3d73347a6c071f2b4140bffefc9b  Airlock_0.1.1_aarch64.dmg
72e7bc174e53c901cbca9a52af92615bb4e44ff094d19d919a112cc66824125a  Airlock_0.1.1_aarch64.app.zip
```

アプリを開く前に実行します。

```bash
shasum -a 256 -c SHA256SUMS-v0.1.1.txt
```

詳細は [installation guide](../installation.md) を参照してください。

## セキュリティと制約

これは**プレリリースのテクニカルプレビュー**であり、本番セキュリティの保証ではありません。
アプリは ad-hoc 署名で、Apple Developer ID 署名と公証はありません。公式 Release からのみ
取得し、checksum を確認してから Gatekeeper の手順に従ってください。

Go、Rust、frontend、npm package、artifact checksum、厳密な code signature の検証を
実施していますが、独立した本番セキュリティ監査は完了していません。LAN ingress を公開
インターネットに公開せず、無制限 SSH exec には専用の最小権限 account を使用し、command
audit 有効時は command argument に Secret を入れないでください。実際の認証情報を使う前に
[security policy](../../SECURITY.md) をお読みください。

## 既知の制限

- Intel macOS、Windows、Linux の installer はありません。
- Developer ID 署名と Apple notarization はありません。
- Capability に TTL、one-time 使用、接続単位の approval はありません。
- LLM usage は任意のメモリ内集計であり、課金データではありません。

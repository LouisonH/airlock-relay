# Airlock v0.1.0 - Technical Preview

Released: July 30, 2026

[English](v0.1.0.md) | [简体中文](v0.1.0.zh-CN.md)

Airlock v0.1.0 is the first downloadable technical preview of the native
credential-isolation relay. It lets an agent, LLM, script, or another local
device use a narrowly scoped route without receiving the protected upstream
URL, account password, SSH identity, or provider API key.

## Highlights

- Fixed-route HTTP/Wget forwarding with streaming Range downloads.
- Dual-session SSH relay with custom local authentication, strict upstream host
  key pinning, a user-editable exact-command mode, unrestricted non-interactive
  exec behind a high-risk confirmation, and optional command history.
- In-window SSH credential entry and Host Key review, with multiple local
  usernames allowed to map to the same upstream address.
- Existing SSH mapping management for protected-host replacement, local
  username-to-host selection, local credential rotation, deletion, and manual
  health checks.
- Sanitized activity for connection attempts against disabled routes and a
  manual connectivity check for the protected local proxy.
- OpenAI-compatible and Anthropic-compatible LLM routing with a separate local
  API key, model and output limits, rate/concurrency policy, SSE streaming, and
  optional in-memory call and token totals.
- Direct, Clash-compatible proxy, and automatic egress selection.
- A prompt-free local `0600` file store as the standard default, an opt-in
  stricter macOS Keychain mode, and guided migration between them.
- Native Tauri desktop interface with light/dark/system appearance, accent
  themes, information density, motion, and refresh preferences.
- User-triggered public-release version checks, an embedded multilingual guide,
  and static Pages documentation. Version checks never download or install an
  update automatically.
- Composable safe route filters for name, alias, local entry, kind, state,
  health, and egress, with health checks scoped to the filtered result set.
- npm CLI `status`, `platform`, `doctor`, and `release` commands for release
  contracts and installer verification without launching the app.
- Loopback-only listeners by default, plus an explicitly confirmed private-LAN
  relay mode for trusted local networks.

## Download

This release supports **Apple Silicon** and **macOS 12 or newer**.

- `Airlock_0.1.0_aarch64.dmg`
- `Airlock_0.1.0_aarch64.app.zip`
- `SHA256SUMS.txt`

Verify the download before installation:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Then follow the [installation guide](../installation.md).

## Security Notice

This is a prerelease technical preview, not a production security claim. The
application is ad-hoc signed but does not have an Apple Developer ID signature
and is not notarized. macOS will show an unidentified-developer warning on the
first launch. The code has automated race, unit, integration, frontend, Rust,
and lint checks, but no independent production security audit has been
completed.

Read the [security policy and threat boundaries](../../SECURITY.md) before
using real credentials. In particular:

- v0.1.0 local capabilities have no TTL and are not one-time credentials.
- LAN mode must not be forwarded to the public Internet.
- Unrestricted SSH exec is effectively remote command execution as the
  configured upstream user.
- Command audit records full commands, including potentially sensitive
  arguments.
- LLM token statistics do not persist prompts or response bodies, but the
  totals reset when the sidecar restarts.

## Known Limitations

- No Intel, Windows, or Linux binary package is included.
- No Developer ID signing or Apple notarization.
- No TTL, one-time capability, or per-connection approval workflow.
- HTTP capability rotation is not yet available from the desktop UI.
- LLM usage and limits are in memory rather than persistent accounting.
- Closing the main window keeps Airlock in the menu bar; choose **Quit** from
  the menu-bar item to stop the sidecar.

# Airlock v0.1.5 - 対話 Shell とクロスプラットフォーム基盤リリース

リリース日: 2026 年 8 月 1 日

[English](v0.1.5.md) | [简体中文](v0.1.5.zh-CN.md) | [日本語](v0.1.5.ja.md)

## 追加

- route ごとの対話型 SSH Shell（default で無効）。`allow_interactive_shell: true`
  （`allow_all_commands: true` が必要）を設定すると、PuTTY や `ssh` client は
  上流 Shell へ直接入り、Airlock は保存済みの上流認証情報を注入します。PTY
  metadata はこの switch が有効なときだけ上流へ転送されます。
- 非対話 route への plain Shell request は拒否ではなく案内を返し、単一の完全一致
  コマンドを設定した route は Shell request 時にそのコマンドを実行します。
- SSH コマンド向け protected keyword egress rewrite。
- 明示的な route ごと SFTP 権限（default で無効）。modern `scp`/SFTP client 向け。
- Windows x64/x86/arm64 と Linux x64/arm64/ARMv7 向け Core/CLI クロスコンパイル、
  owner-only Windows Named Pipe 制御、Credential Manager / Secret Service バック
  エンド、Linux native prompt、fail-closed な CI preview installer 契約。Windows
  preview installer は手動テスト用に本リリースへ添付されますが、署名済み・固定
  checksum 付きの公開 installer ではありません。

## 修正

- 対話 Shell の PTY 寸法が転置されたまま上流へ渡され、端末入力表示が乱れる問題を
  修正。上流セッションは client の実際の行数・列数を受け取ります。

の production-readiness audit が適用されますが、独立した第三者認定ではありませ

LOCAL CREDENTIAL BOUNDARY

Airlock

把能力交给 Agent，把凭据留在本机。

Airlock 使用固定本地路由、可撤销凭据与最小权限策略，为 HTTP、SSH 和 LLM 请求隔离真实上游地址、密码与 API Key。

下载安装 v0.1.7 了解安全模型
NPM INSTALL npm install -g airlock-relay && airlock-installer install --open

ROUTE TYPES

三种入口，同一条保护边界

调用者看到的只是稳定的本地入口和属于该路由的本地凭据。

01HTTP / WGET

固定 URL 转发

隐藏上游基址与 Authorization，限制方法、Query 和重定向，支持 Range 下载。

  • GET / HEAD 白名单
  • Range / 206 流式下载
  • Direct / Proxy / Auto 出口
02SSH

双会话 SSH 终止

Airlock 分别终止本地与上游 SSH 会话，用完全独立的账号和凭据建立连接。

  • 自定义本地密码 / 公钥
  • 精确命令或受控的完整 exec
  • 固定 Host Key 与可选审计
03LLM API

本地二次 API Key

兼容 OpenAI 与 Anthropic 协议，只注入受保护的上游 Key，并限制模型与资源用量。

  • 模型、输出、速率和并发限额
  • 随机或自定义二次 Key
  • 可选调用与 Token 统计

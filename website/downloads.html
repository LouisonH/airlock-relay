DOWNLOAD & INSTALL

下载与安装

所有安装包都附带固定 SHA-256 校验和；Linux 产物另有 GPG 签名。校验失败时安装器会拒绝执行。

NPM INSTALL npm install -g airlock-relay && airlock-installer install --open
macOS12+

Apple Silicon / Intel

DMG 安装到 ~/Applications；Apple Silicon 版本随 npm 包内置，Intel 版本从 Release 下载并校验。

arm64 DMG ↗ x64 DMG ↗
npm install -g airlock-relay && airlock-installer install --open

ad-hoc 签名，未经 Apple 公证；首次打开需 Gatekeeper 确认，请先核对 SHA-256。

Windows10+

x64 / x86 / arm64

NSIS 安装包静默安装；npm 安装器会先下载固定校验和的安装程序并核验。

x64 ↗ x86 ↗ arm64 ↗
npm install -g airlock-relay && airlock-installer install --open

预览安装包未代码签名，会出现 UAC 提权提示，SmartScreen 可能警告。

Linuxx64 / arm64

AppImage + GPG 签名

AppImage 安装到 ~/.local/bin；64 位树莓派可直接使用 arm64 版本，32 位 armv7 见文档构建脚本。

x64 AppImage ↗ arm64 AppImage ↗
npm install -g airlock-relay && airlock-installer install --open

GPG 公钥与 .sig 随 Release 发布；无 FUSE 时用 --appimage-extract-and-run。

SHA-256固定校验和下载校验清单 ↗
GPGLinux 发布签名导入公钥 ↗
RELEASE全部平台产物GitHub Release ↗

PLATFORM CONTRACT

先识别系统，再选择受验证的安装路径

同一个 npm 包会识别当前操作系统与 CPU；安装器只会在公开工件及 SHA-256 已固定时执行。

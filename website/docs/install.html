安装与校验

无论从哪个平台开始，安装路径都遵循同一原则：从官方渠道获取、核对 SHA-256（Linux 另有 GPG 签名）、失败即拒绝。

01

系统要求

  • macOS 12 Monterey 或更高（Apple Silicon 与 Intel）。
  • Windows 10 或更高（x64、x86/i686、arm64）。
  • Linux x64 或 arm64 桌面发行版（AppImage）；64 位树莓派系统可直接安装。
  • Linux ARMv7（32 位树莓派）需在设备端构建，见跨平台章节。
02

通过 npm 安装（推荐）

npm install 本身无副作用：不会下载、启动应用或修改系统设置。安装命令由 airlock-installer 执行，它先下载当前平台的固定校验和产物并核验。

全平台通用
npm install -g airlock-relay
airlock-installer install --open

行为分平台：macOS 安装到 ~/Applications；Windows 静默运行 NSIS（出现 UAC 提示）；Linux 安装 AppImage 到 ~/.local/bin/Airlock.AppImage。可用 --output <目录> 指定 Linux 安装目录。

03

校验安装包

从 Release 下载 SHA256SUMS-v0.1.6.txt 与对应产物后：

SHA-256 校验（macOS/Linux）
shasum -a 256 -c SHA256SUMS-v0.1.6.txt
GPG 校验（Linux AppImage/deb）
gpg --import Airlock-gpg-pubkey.asc
gpg --verify Airlock_0.1.6_amd64.AppImage.sig Airlock_0.1.6_amd64.AppImage

公钥指纹：6DE9B706 DF0FBFD8 43F43FE0 A6C7913E B32FAD7E（Airlock Release Signing）。

04

升级

  1. 检查当前版本：airlock-installer version。
  2. 执行 npm install -g airlock-relay@latest 更新包。
  3. 再次执行 airlock-installer install：macOS 原子替换应用；Windows 运行新版安装器；Linux 覆盖 AppImage。
  4. 升级后核对 airlock-installer doctor 与路由健康检查。
数据保留

升级不会删除路由配置与 Secret；Server Core 升级请先备份，见运维章节。

05

卸载

  • macOS：删除 ~/Applications/Airlock.app；可选删除 ~/Library/Application Support/io.airlock.relay 等数据目录。
  • Windows：设置 → 应用 → Airlock → 卸载（或 MSI 卸载命令）。
  • Linux：删除 ~/.local/bin/Airlock.AppImage；若使用 deb 安装，执行 sudo dpkg -r airlock。
  • 全局 CLI：npm uninstall -g airlock-relay。

Install and verify

Every platform follows the same principle: obtain from the official channel, verify the SHA-256 (plus GPG on Linux), and fail closed on any mismatch.

01

Requirements

  • macOS 12 Monterey or newer (Apple Silicon and Intel).
  • Windows 10 or newer (x64, x86/i686, arm64).
  • Linux x64 or arm64 desktop distributions (AppImage); 64-bit Raspberry Pi OS installs directly.
  • Linux ARMv7 (32-bit Pi) builds on-device; see platforms.
02

Install via npm (recommended)

npm install itself has no side effects. airlock-installer downloads and verifies the pinned artifact for your platform before installing.

All platforms
npm install -g airlock-relay
airlock-installer install --open

Behavior by platform: macOS installs to ~/Applications; Windows runs the NSIS installer silently (UAC prompt); Linux installs the AppImage to ~/.local/bin/Airlock.AppImage. Use --output <dir> to choose the Linux destination.

03

Verify the package

Download SHA256SUMS-v0.1.6.txt and the matching artifact from the release:

SHA-256 (macOS/Linux)
shasum -a 256 -c SHA256SUMS-v0.1.6.txt
GPG (Linux AppImage/deb)
gpg --import Airlock-gpg-pubkey.asc
gpg --verify Airlock_0.1.6_amd64.AppImage.sig Airlock_0.1.6_amd64.AppImage

Public key fingerprint: 6DE9B706 DF0FBFD8 43F43FE0 A6C7913E B32FAD7E (Airlock Release Signing).

04

Upgrade

  1. Check the current version: airlock-installer version.
  2. Run npm install -g airlock-relay@latest.
  3. Run airlock-installer install again: macOS replaces the app atomically; Windows runs the new installer; Linux overwrites the AppImage.
  4. Re-run airlock-installer doctor and route health checks.
Data retention

Upgrades never delete route configuration or secrets. For Server Core, back up first; see operations.

05

Uninstall

  • macOS: delete ~/Applications/Airlock.app; optionally remove ~/Library/Application Support/io.airlock.relay.
  • Windows: Settings → Apps → Airlock → Uninstall (or the MSI uninstall command).
  • Linux: delete ~/.local/bin/Airlock.AppImage; for deb installs run sudo dpkg -r airlock.
  • CLI: npm uninstall -g airlock-relay.

インストールと検証

すべてのプラットフォームで同じ原則：公式チャネルから取得し、SHA-256（Linux は GPG も）を検証し、不一致なら実行を拒否します。

01

システム要件

  • macOS 12 Monterey 以降（Apple Silicon / Intel）。
  • Windows 10 以降（x64 / x86 / arm64）。
  • Linux x64 / arm64 デスクトップ（AppImage）。64bit Raspberry Pi OS は直接インストール可能。
  • Linux ARMv7（32bit Pi）はデバイス上でビルドします。プラットフォーム参照。
02

npm でインストール（推奨）

npm install 自体に副作用はありません。airlock-installer が現在のプラットフォーム用の固定 checksum アーティファクトをダウンロードし、検証してからインストールします。

全プラットフォーム共通
npm install -g airlock-relay
airlock-installer install --open

macOS は ~/Applications、Windows は NSIS のサイレント実行（UAC 確認）、Linux は ~/.local/bin/Airlock.AppImage にインストールされます。

03

インストールパッケージの検証

Release から SHA256SUMS-v0.1.6.txt と対象アーティファクトをダウンロードします。

SHA-256（macOS/Linux）
shasum -a 256 -c SHA256SUMS-v0.1.6.txt
GPG（Linux AppImage/deb）
gpg --import Airlock-gpg-pubkey.asc
gpg --verify Airlock_0.1.6_amd64.AppImage.sig Airlock_0.1.6_amd64.AppImage

公開鍵フィンガープリント：6DE9B706 DF0FBFD8 43F43FE0 A6C7913E B32FAD7E。

04

アップグレード

  1. airlock-installer version で現在のバージョンを確認。
  2. npm install -g airlock-relay@latest。
  3. airlock-installer install を再実行（macOS は原子的置換、Linux は AppImage 上書き）。
  4. airlock-installer doctor とルートのヘルスチェックで確認。
データ保持

アップグレードでルート設定や Secret は削除されません。Server Core は先にバックアップしてください。

05

アンインストール

  • macOS：~/Applications/Airlock.app を削除。必要に応じて ~/Library/Application Support/io.airlock.relay も削除。
  • Windows：設定 → アプリ → Airlock → アンインストール。
  • Linux：~/.local/bin/Airlock.AppImage を削除。deb なら sudo dpkg -r airlock。
  • CLI：npm uninstall -g airlock-relay。
